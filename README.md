# osFoundry IoT Device Simulator

This Python script simulates a collection of IoT devices within an 'osFoundry Room' environment. It demonstrates basic device operations like starting, collecting data, and stopping, mimicking the needs of low-level hardware interaction.

## Language

`python`

## How to Run

Run the script using a Python interpreter: `python osfoundry_simulator.py`
